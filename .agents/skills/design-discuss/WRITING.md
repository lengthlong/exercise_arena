# 内核的写法

所有设计文字先按本文件的共守规则写；`adr/` 与术语表的专属写法也在这里。术语表位置按 `CLAUDE.md` 内核地图的 `context` 规则读取。其余文件的用途、专属表达与验证，在本工作区的 `design-writing`。

在设计工作区里以本文件为准：全局的 `domain-modeling` skill 可以借它的术语表格式，但它「术语一定案就当场改 `CONTEXT.md`」与「ADR 放在 `docs/adr/`」都不适用 —— 这里改设计文件要经落盘（`CLAUDE.md` 守则第 1 条），ADR 在根目录 `adr/`。

## 内容标准

- **先确认用途，再评价形式。** 评价采用该文件当前设计阶段的标准。
- **留白是合法的设计状态。** 用户说「不假设、不决定」的部分显式标为留白，只写它是什么位置的东西；宁留一个边界清晰的开放问题，不拿推测去填。

## 共守的语义规则

- **术语一致。** 概念用配置指定的术语表的首选词，流程词用 `CLAUDE.md` 的定义；工作区专属表达按本工作区 `design-writing`。命令、路径、字段、接口与原始错误等机器字面量按代码格式写，保持原样。
- **按用途组织。** 操作说明先写执行所需的条件，再写动作。一个可执行步骤写一个主要动作与对象；存在责任歧义时写出执行者，区分人工动作与系统行为。必须顺序执行的动作分成子步骤，不可分操作可放在一起。结果或验证只写有依据的内容。流程阶段可以包含多个子步骤，不为短句新增阶段。
- **描述与理由保留叙述。** 写清主干与指代，按信息组织短句、短段；条件、否定与原因仍连着它们限定的命题。概念说明与取舍不强改成操作清单，不设中文字符阈值。
- **固定原文保留。** 引用、反例与机器内容不能为风格改动事实；说明文字仍按共守规则写。需保留的术语违例按下面的显式豁免标记。
- **改写保真。** 对照原文保留事实、数字、条件、例外、否定范围、因果关系、确定程度与机器字面量；事实、推断与未知分别写明。改变这些含义属于新语义，回到讨论裁决。

## 术语检查的边界

`./check.sh` 按 `.discuss_design.yaml` 的 `design` 范围检查说明文字，无条件违例仍导致失败。围栏与缩进代码、行内代码、URL 和链接目标不扫描，链接显示文字仍检查。只有配置指定的术语表中以 `_Avoid_:` 或 `_Avoid_：` 起头的列表行豁免；其他正文含 `_Avoid_` 仍检查。

固定引用或反例需保留违例词时，在同一行加 `<!-- design-terms-ignore: 理由 -->`，理由不能为空。标记只豁免这一行；在代码或链接目标里演示标记不豁免外部正文。文件枚举、规则扫描或处理器失败须报错，不能算无命中；只有全部必需检查成功执行且无违例，才返回退出码 0。

机械检查验证确定的格式与术语规则；句长、指代、责任主体、技术正确性与改写保真由写作者对照原文核对。保护区与豁免通过不代表其内容正确。

## ADR（`adr/`）

- **只写理由与取舍**，不复述设计的结构。
- **三条标准全过才立档**：难以逆转 / 后人无背景会困惑 / 有真实取舍。
- **按信息组织短句、短段**，讲清背景、决定、理由与必要取舍，不固定句数或段数；有未决的尾巴就加「未决」段。
- 理由由 agent 取证、论证并提出，说明与用户决定的关系，不把推断冒充用户未表达的动机。新取舍改变已裁含义时回对应题；不为已摆明的理由再设必问环节。
- **文件名是一句结论**：`NNNN-<陈述句>.md`（`0001-step-binds-agent-directly`），不是名词短语。
- **论证失效时，按新裁决重写 ADR**；名称失实时改名并更新全部引用。

## 术语表（配置项 `context`）

- **只定义「是什么」**，一两句；不讲理由，不写实现细节。
- **每条带 `_Avoid_` 列表**：同一个概念有几种说法时，选最好的一个，其余列进 `_Avoid_`。
- **词条标题一律中英双名**：`English（中文）` 或 `中文（English）`。最自然的译名正落在该词自己的 `_Avoid_` 里时，改用取自定义的说法，或解禁那个词。
- **无条件违例的 `_Avoid_` 词**（出现即是错）加进 `.discuss_design.yaml` 的 `terms`，由 `./check.sh` 机械检查；只在特定语境才算违例的词不加。

## 改完之后

- **对照实际稿自查。** 逐项核对共守规则中的保真内容，不把拟改样例或落盘前核销表的复审当成最终稿验证。现有落盘前独立复审核对拟改内容与验证计划；不新增逐次改写的独立复审。记录实际对照结果，新语义回讨论。
- **按实际影响同步。** 术语或文件名变化时，检索当前文件里的全部相关用法与引用，逐项修改或确认不适用；冻结的记录与 `publish/` 的已有正文除外。
- **跑 `./check.sh`**，退出码 0 才通过。
