# 练习场页面

练习场页面（`app/arena.html`）的字段形状、计算规则、视图与错误分支。领域规则见 `domain/OVERVIEW.md`，词见 `domain/CONTEXT.md`。

## 运行时能力

页面声明 `db`、`assets`、`sample`（`images: true`）和 `downloads`。

| 能力 | 用途 | 拿不到时（`use()` 为 `null` 或调用被拒） |
|---|---|---|
| `db` | 存错题、题组、检验卷、设置 | 页面只显示「数据不可用」，不提供任何操作 |
| `assets` | 存题目与题组的照片 | 隐藏拍照入口，只能贴文字录入 |
| `sample` | 照片或文字 → 题组与错题草稿 | 录入改为手填空白草稿 |
| `downloads` | 导出：保存 YAML 文本文件 | 隐藏导出入口 |

## 数据

所有日期是设备本地日期，写成 `YYYY-MM-DD`。

### `exercises/{id}`：错题

作答嵌在错题文档的 `attempts` 数组里，不单独成集合：一份数据库最多 25,000 份文档，作答按次数增长，嵌入后文档数只随错题数增长。

| 字段 | 类型 | 说明 |
|---|---|---|
| `subject` | `"english"` · `"math"` · `"science"` | 必填 |
| `topic` | 字符串 | 专题 id，必填，取自 `TAXONOMY.md` 所述的体系 |
| `concept` | 字符串或 `null` | 概念 id |
| `qtype` | 字符串或 `null` | 题型 id |
| `format` | `"mcq"` · `"pick"` · `"short"` · `"open"` | 作答形式：选择、选词、短答、主观 |
| `stem` | 字符串 | 题目文字；只有照片时可以为空 |
| `images` | 字符串数组 | 照片的 asset id |
| `options` | 字符串数组 | 选择题的选项，按 A、B、C、D 顺序；其他形式为空数组 |
| `answer` | 字符串 | 选择题为选项字母；选词题为词表中的词；短答题为首选答案；主观题为标准答法（句子改写写整句） |
| `accepted` | 字符串数组 | 短答题的全部可接受答案，含 `answer`；其他形式为空数组 |
| `solution` | 字符串 | 讲解，按「讲解格式」分三段；得分关键词写成 `[[关键词]]`，显示时高亮 |
| `wrongAnswer` | 字符串 | Sophia 当时的错答 |
| `mustUse` | 字符串数组，可省 | 只用于主观题：必须用的词；用「…」分开的项表示须按顺序出现的几部分，例如 `Neither…nor` |
| `cause` | `"concept"` · `"misread"` · `"careless"` · `"incomplete"` | 错因：概念没懂、审题错、粗心、答法不完整 |
| `source` | 字符串 | 出处，例如「2026 P5 SA2 卷二第 7 题」 |
| `createdAt` | 日期 | 录入日期 |
| `recordedAt` | 时刻，可省 | 录入时刻，设备本地时间，写成 `YYYY-MM-DDTHH:mm`；页面录入与对话录入都写；旧错题没有 |
| `attempts` | 作答数组 | 见下表，按时间顺序追加 |
| `step` · `due` · `mastered` · `wrongCount` · `lastAttemptAt` | 派生 | 由 `createdAt` 与 `attempts` 推出，见「复习阶梯的计算」；每次写 `attempts` 时一并写回 |
| `setId` | 字符串或 `null`，可省 | 所属题组；省略等同 `null`，即独立的错题 |
| `setPos` | 数，可省 | 组内顺序；本批按识别或草稿顺序，后来补录的取组内最大值加一 |
| `test` | 布尔，可省 | 验证用的测试数据标记 |

作答：

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | 日期 | 作答日 |
| `mode` | `"daily"` · `"paper"` | 每日重做或检验卷 |
| `paperId` | 字符串或 `null` | 检验卷 id |
| `response` | 字符串 | 她的回答 |
| `result` | `"right"` · `"partial"` · `"wrong"` | 对、部分对、错 |
| `judgedBy` | `"auto"` · `"self"` · `"parent"` | 自动判、自评、改判（存储值仍为 `"parent"`） |
| `at` | 时刻，可省 | 作答时刻，设备本地时间，写成 `YYYY-MM-DDTHH:mm`；旧作答没有 |

### `sets/{id}`：题组

| 字段 | 类型 | 说明 |
|---|---|---|
| `subject` | 同错题 | 必填；组里的错题与它同科目 |
| `title` | 字符串 | 例如「义卖会传单」，列表与选择用 |
| `text` | 字符串 | 材料文字；只有照片时可以为空 |
| `images` | 字符串数组 | 材料照片的 asset id |
| `wordBank` | 字符串数组，可省 | 词表；组内选词题从中选答 |
| `source` | 字符串 | 出处 |
| `createdAt` | 日期 | |
| `test` | 布尔，可省 | 测试数据标记 |

题组随组内第一道错题保存时写入：先写题组，再写错题。页面 `db` 没有事务，中途失败可能留下没有错题挂着的题组；页面不显示这样的题组，它也不出现在「所属题组」的选项里。

### `papers/{id}`：检验卷

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | 字符串 | 例如「科学 · 水、繁殖 · 10-14」 |
| `createdAt` | 日期 | |
| `subject` | 同上 | |
| `topics` | 字符串数组 | 专题 id；空数组表示该科目全部专题 |
| `count` | 数 | 要的题数 |
| `exerciseIds` | 字符串数组 | 抽出的错题，按卷面顺序（同组合并后） |
| `status` | `"open"` · `"done"` | 未做、已出结果 |
| `finishedAt` | 时刻，可省 | 完成时刻，格式同作答的 `at`；旧检验卷没有 |
| `takenOn` | —— | 不再写入，已有的忽略 |
| `score` | —— | 不再写入，已有的忽略；得分见下文「得分」 |
| `test` | 布尔，可省 | 测试数据标记 |

### `settings/main`

| 字段 | 默认 | 说明 |
|---|---|---|
| `dailyLimit` | `10` | 每日重做的题数上限，设置页可改 |

## 复习阶梯的计算

间隔：第 1 级 1 天，第 2 级 2 天，第 3 级 4 天，第 4 级 7 天。错题的状态由录入日开始，按 `attempts` 的顺序逐次推出：

1. 起点：`step = 1`，`due = createdAt + 1`，`mastered = false`，`wrongCount = 1`（录入时那次错）。
2. 对每次作答，`lastAttemptAt` 记为作答日，再按结果处理：
   - 未掌握、对：第 4 级则 `mastered = true`、`due = null`；否则升一级，`due = 作答日 + 新级间隔`。
   - 未掌握、部分对：留在原级，`due = 作答日 + 本级间隔`。
   - 未掌握、错：回第 1 级，`due = 作答日 + 1`，`wrongCount + 1`。
   - 已掌握、错：`mastered = false`，回第 1 级，`due = 作答日 + 1`，`wrongCount + 1`。
   - 已掌握、对或部分对：不变。

改判任何一次作答后，从起点重新推出，写回派生字段。

## 判对

| 作答形式 | 规则 |
|---|---|
| 选择 | 选中的字母等于 `answer` 为对，否则为错；`judgedBy = "auto"` |
| 选词 | 点选的词与 `answer` 规范化后相等为对，否则为错；`judgedBy = "auto"` |
| 短答 | 回答与 `accepted` 中任一项规范化后相等为对，否则为错；`judgedBy = "auto"` |
| 主观 | 提交后显示 `solution`，关键词高亮；她选对、部分对或错；`judgedBy = "self"` |

规范化：转小写；去掉首尾空格，连续空格并成一个；去掉句末的 `.`；两边都是数字时（允许数位间的逗号，例如 `1,000`），按数值比较，`0.50` 与 `0.5` 相等。

在错题详情与检验卷详情里，可以把任何一次作答改为对、部分对或错，`judgedBy` 改为 `"parent"`（显示为「改判」）。

提交前的提醒：只对 `mustUse` 非空的主观题。Sophia 一律写完整的改写句，含给定的词。检查两项，任一不满足就先显示提醒，再点一次照交：

- `mustUse` 每一项都出现在回答里：不分大小写，按整词或词组匹配；含「…」的项拆成几部分，各部分须按顺序出现。
- 只写了一句：句末标点（`.` `!` `?`）后面还有文字即算多句；引号里的标点，以及 Mr. Mrs. Ms. Dr. St. 这几个缩写里的句点，不算。

显示：`[[ ]]` 在题组材料与题目文字里显示为下划线（例如改错的划线词），在讲解与标准答法里显示为高亮。词表在屏幕上不在材料里另列，只作为每道选词题的作答按钮。

## 讲解格式

`solution` 按三段书写，每段以标记开头：

```text
Key idea: 一句话说清考点
Steps:
1. 第一步
2. 第二步
Watch out: 常见错误（可以一行或几行）
```

- 显示为三个带小标题的块：Key idea、Steps（编号列表；`1.` 或 `- ` 开头的行都算一步）、Watch out。标记不分大小写，段落顺序不限，缺的段不显示。
- `[[ ]]` 照常高亮。
- 没有这些标记的讲解（例如手填的旧文字）按空行分段显示。
- 识别提示词要求 Claude 按这个格式写讲解；草稿表单的讲解输入框提示这个格式。

## 照片

做题与查看的各处（Today 的每日重做、做检验卷、错题详情、检验卷详情），题目照片与题组材料照片都默认收起，显示为「Show photo (n)」，点开才显示。题组材料本身收起时，展开后其中的照片仍需再点。材料文字照常显示。录入草稿区的缩略图照常显示。

## 每日重做

进入时算一次清单，本次进入期间不变：

1. 取未掌握且 `due` 不晚于今天的错题。
2. 合成单元：独立的错题各成一个单元；同一题组的到期错题合成一个单元，组内按 `setPos` 排。
3. 单元排序：按单元里最早的 `due` 从早到晚；相同时按单元里最早的 `createdAt`。
4. 逐个放入：放入后总题数不超过 `dailyLimit` 就放入；放不下就跳过这个单元，继续看下一个。清单还空着时，第一个单元整组放入，即使超过上限。

逐题作答，每题判完立即写回该错题。题组的材料在组内第一题完整显示，第二题起默认收起，可以展开；照片另按「照片」一节默认收起。

## 检验卷

1. 选科目、专题（可多选，不选即全部）和题数。
2. 候选：该科目、所选专题内的全部错题，已掌握的也算。
3. 排序：`wrongCount` 从多到少；相同时已掌握的在前；再按 `lastAttemptAt` 从早到晚，从未作答的最先。取前 `count` 题。
4. 卷面合并：按上一步的顺序，遇到某题组的第一道题时，把同组被抽中的题按 `setPos` 接在它后面。按这个卷面顺序写成 `papers` 文档，`status = "open"`。抽题预览、作答与检验卷详情都按卷面顺序显示，题组材料只出现一次，放在组内第一题前面。
5. 作答：Sophia 在 Today 打开未做的检验卷，逐题作答，中途不显示对错与答案。交卷时，对有必须用的词的题统一提醒一次。交卷后，选择、选词与短答题自动判；主观题显示讲解，由她自评。全部判完后，每题追加一次 `mode = "paper"` 的作答，检验卷写入 `status = "done"` 与 `finishedAt`。

得分：取 `exerciseIds` 中仍在的错题，找出每题 `paperId` 等于本检验卷的作答，按结果数对、部分对、错，合计为仍在的题数；已删的错题不计入分子与分母。每次显示时计算，不存储，所以任何改判都会反映到得分。

检验卷详情：在「检验卷」标签的列表里点「查看详情」打开。显示完成时刻（没有 `finishedAt` 的显示「未记录」）、得分；按卷面顺序每题显示题组材料（一次）、题目、她的回答、正确答案、结果、判定方式、改判下拉框与错题详情链接；错题已删的显示「已删除」。改判后重推该错题的阶梯。


删除检验卷：作答与阶梯不变；这些作答在错题详情的作答记录里显示为「检验卷（已删除）」。

## 错题列表

- 每条显示录入时刻（`recordedAt`；旧错题只显示 `createdAt` 日期）。
- 排序键：录入时间、到期日、错的次数（`wrongCount`）、上次作答（`lastAttemptAt`），每个都可切换升序、降序；默认录入时间新的在前。
- 没有值的（例如从未作答、已掌握而没有到期日）无论升序降序都排最后；值相同时按录入时间新的在前；只有日期的旧错题按当天 00:00 计。
- 每页 20 条，下方有上一页、下一页与页码；改筛选或排序时回到第 1 页。

## 导出

设置页的「导出」按钮生成一份 YAML 文本，经 `downloads` 保存为 `arena-export-<日期>.yaml.txt`（平台不允许保存 `.yaml` 扩展名）。被拒或不可用时显示原因。内容：

- `exportedAt`：导出时刻，设备本地 `YYYY-MM-DDTHH:mm`。
- `settings`：`settings/main` 的字段。
- `exercises`：每道错题的全部字段，带 `id`，含 `attempts` 与阶梯派生字段。
- `sets`：每个题组的全部字段，带 `id`，含 `wordBank`。
- `papers`：每张检验卷的全部字段，带 `id`；`score` 以算出的 `{right, partial, wrong, total}` 覆盖旧值。
- 各处 `images` 字段保留名称，值换成照片张数，不含照片本身。
- 字符串一律写成 YAML 双引号字符串，按需转义。

## 视图

页面顶部是一排标签「Today · 录入 · 错题 · 检验卷 · 设置」，打开时在 Today。做题的页面用英文，管理的页面用中文。

| 标签 | 内容 |
|---|---|
| Today | 每日重做的题数与开始按钮；未做的检验卷；重做时一次一题，属于题组的题上方显示材料，判完显示正确答案与讲解，概念、题型可链到知识图；做检验卷时整卷作答、交卷、自评、看得分（英文） |
| 录入 | 拍照或贴文字 → 题组与错题草稿 → 核对 → 保存；也可直接手填，或新建题组 |
| 错题 | 筛选、排序、分页的错题列表；详情与作答记录；编辑（含所属题组）；改判；删除；详情里显示题组并可编辑题组 |
| 检验卷 | 组卷；未做与做完的检验卷列表；查看详情与改判；删除 |
| 设置 | 每日重做的题数上限；导出 |

## 照片与文字录入

1. 选科目（可选），然后拍照、选照片，或贴一段文字。
2. 有照片时，逐张上传到 `assets`，记下 id。
3. 调 `sample.json`：输入写明任务，附该科目的专题、概念、题型 id 与名称，以及要回的 JSON 形状；照片作为 `images` 一起发出。任务要求：只为看得出 Sophia 做错的题出草稿（她的作答或老师批改可见时）；看不出时全部列出，核对时删。几道题共用一份文章、图或实验装置时，另列一份题组。语法完形把框里的词放进题组的 `wordBank`，每个空作为一道 `pick` 小题；改错把划线词在材料与题目里写成 `[[词]]`，每个划线词一道短答小题；句子改写作为主观题，标准答法写整句，并填 `mustUse`。讲解按「讲解格式」三段写。
   - 回的形状：`{sets, drafts}`。`sets` 是题组草稿数组，每份含 `title`、`text`、`source`，可含 `wordBank`；`drafts` 是错题草稿数组，每份含 `exercises` 文档除 `images`、`attempts`、`setId`、`setPos` 与派生字段外的字段，另加 `set`：本批 `sets` 里的序号，或 `null`。
4. 照片归属：本批有题组时，全部照片挂到本批每个新题组上，独立的错题草稿不挂；本批没有题组时，每份错题草稿都挂上全部照片。
5. 草稿区：题组卡片（科目、标题、材料文字、照片、出处、词表）在上，所属的错题草稿在下；独立草稿在后。每份错题草稿有「所属题组」下拉框，选项为：无、本批新建的题组、已存的题组，只列同科目的。另有「新建题组」按钮，加一张空白题组卡片。作答形式可选「选词」，答案从所属题组的词表里选；主观题有「必须用的词」输入（`;` 分隔）；题组卡片的「词表」用 `;` 或换行分隔；题目文字与材料文字的输入框提示 `[[ ]]` 会显示为下划线。逐份核对，可删照片、删草稿、加空白草稿；讲解输入框提示三段格式。
6. 保存：错题草稿校验科目与专题必填；选词题必须属于带词表的题组，答案在词表中；题目文字或照片至少一项，属于题组的可以由题组的材料文字或照片满足。属于本批新题组的，组内第一道保存时先写题组；`setPos` 按草稿顺序。写成一份 `exercises` 文档，`attempts` 为空，写入 `recordedAt`，派生字段按起点写入。

编辑错题时，`setId` 与 `setPos` 随草稿保留；改选题组时，`setPos` 取新组最大值加一。一道错题移出题组或被删除后，原题组里没有错题挂着，就删除这个题组。题组没有单独的删除入口：删掉或移出组里全部错题，题组随之删除。在错题详情里可以编辑题组的标题、材料文字、照片、出处与词表。保存时，若组内选词题的答案不在新词表中，拒绝保存并列出这些题。

错误分支：

| 情况 | 处理 |
|---|---|
| `sample` 为 `null`，或调用被拒（`not_granted`、`images_unavailable`、`sampling_disabled` 等） | 给一份空白草稿，挂上照片，手填；提示识别不可用 |
| `invalid_json`，或回来的不是 `{sets, drafts}` 形状（也接受只有错题草稿的数组） | 同上，提示识别没有成功 |
| `rate_limited` | 提示稍后再试，不自动重试 |
| 草稿的专题 id 不在体系里 | 专题留空，保存前必须选 |
| 上传照片失败 | 提示失败的照片，其余照常 |

在 Claude Code 对话里录入：agent 先在对话里列出题组与错题草稿，确认后，用 `ArtifactData` 先写 `sets`、再写 `exercises` 文档，字段与派生字段同上，并写 `recordedAt`；有照片时，先把照片上传到页面的 `assets`，再把 id 写进题组或错题的 `images`。agent 只写 `exercises`、`sets` 与 `assets`。

## 留白

- 变式题：将来作为一道错题录入，多一个指向原题的字段。
