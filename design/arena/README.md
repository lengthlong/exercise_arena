# 练习场页面

练习场页面（`app/arena.html`）的字段形状、计算规则、视图与错误分支。领域规则见 `domain/OVERVIEW.md`，词见 `domain/CONTEXT.md`。

## 运行时能力

页面声明 `db`、`assets`、`sample`（`images: true`）和 `downloads`。

| 能力 | 用途 | 拿不到时（`use()` 为 `null` 或调用被拒） |
|---|---|---|
| `db` | 存错题、检验卷、设置 | 页面只显示「数据不可用」，不提供任何操作 |
| `assets` | 存题目照片 | 隐藏拍照入口，只能贴文字录入 |
| `sample` | 照片或文字 → 错题草稿 | 录入改为手填空白草稿 |
| `downloads` | 打印：保存一份可打印的检验卷 HTML 文件（页面框架里调不起浏览器打印） | 隐藏打印入口，只能屏幕作答 |

## 数据

所有日期是设备本地日期，写成 `YYYY-MM-DD`。

### `exercises/{id}`：错题

作答嵌在错题文档的 `attempts` 数组里，不单独成集合：一份数据库最多 25,000 份文档，作答按次数增长，嵌入后文档数只随错题数增长。

| 字段 | 类型 | 说明 |
|---|---|---|
| `subject` | `"english"` · `"math"` · `"science"` | 必填 |
| `topic` | 字符串 | 专题 id，必填，取自 `TAXONOMY.md` 所述的体系 |
| `concept` | 字符串或 `null` | 概念 id |
| `qtype` | 字符串或 `null` | 题型 id |
| `format` | `"mcq"` · `"short"` · `"open"` | 作答形式：选择、短答、主观 |
| `stem` | 字符串 | 题目文字；只有照片时可以为空 |
| `images` | 字符串数组 | 照片的 asset id |
| `options` | 字符串数组 | 选择题的选项，按 A、B、C、D 顺序；其他形式为空数组 |
| `answer` | 字符串 | 选择题为选项字母；短答题为首选答案；主观题为标准答法 |
| `accepted` | 字符串数组 | 短答题的全部可接受答案，含 `answer`；其他形式为空数组 |
| `solution` | 字符串 | 讲解；得分关键词写成 `[[关键词]]`，显示时高亮 |
| `wrongAnswer` | 字符串 | Sophia 当时的错答 |
| `cause` | `"concept"` · `"misread"` · `"careless"` · `"incomplete"` | 错因：概念没懂、审题错、粗心、答法不完整 |
| `source` | 字符串 | 出处，例如「2026 P5 SA2 卷二第 7 题」 |
| `createdAt` | 日期 | 录入日期 |
| `attempts` | 作答数组 | 见下表，按时间顺序追加 |
| `step` · `due` · `mastered` · `wrongCount` · `lastAttemptAt` | 派生 | 由 `createdAt` 与 `attempts` 推出，见「复习阶梯的计算」；每次写 `attempts` 时一并写回 |
| `test` | 布尔，可省 | 验证用的测试数据标记 |

作答：

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | 日期 | 作答日 |
| `mode` | `"daily"` · `"paper"` | 每日重做或检验卷 |
| `paperId` | 字符串或 `null` | 检验卷 id |
| `response` | 字符串 | 她的回答；打印卷由家长勾选时为空 |
| `result` | `"right"` · `"partial"` · `"wrong"` | 对、部分对、错 |
| `judgedBy` | `"auto"` · `"self"` · `"parent"` | 自动判、自评、家长判或改判 |

### `papers/{id}`：检验卷

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | 字符串 | 例如「科学 · 水、繁殖 · 10-14」 |
| `createdAt` | 日期 | |
| `subject` | 同上 | |
| `topics` | 字符串数组 | 专题 id；空数组表示该科目全部专题 |
| `count` | 数 | 家长要的题数 |
| `exerciseIds` | 字符串数组 | 抽出的错题，按抽题顺序 |
| `status` | `"open"` · `"done"` | 未做、已出结果 |
| `score` | `{right, partial, wrong}` 或 `null` | 出结果后写入 |
| `test` | 布尔，可省 | 测试数据标记 |

### `settings/main`

| 字段 | 默认 | 说明 |
|---|---|---|
| `dailyLimit` | `10` | 每日重做的题数上限，家长侧可改 |

## 复习阶梯的计算

间隔：第 1 级 1 天，第 2 级 2 天，第 3 级 4 天，第 4 级 7 天。错题的状态由录入日开始，按 `attempts` 的顺序逐次推出：

1. 起点：`step = 1`，`due = createdAt + 1`，`mastered = false`，`wrongCount = 1`（录入时那次错）。
2. 对每次作答，`lastAttemptAt` 记为作答日，再按结果处理：
   - 未掌握、对：第 4 级则 `mastered = true`、`due = null`；否则升一级，`due = 作答日 + 新级间隔`。
   - 未掌握、部分对：留在原级，`due = 作答日 + 本级间隔`。
   - 未掌握、错：回第 1 级，`due = 作答日 + 1`，`wrongCount + 1`。
   - 已掌握、错：`mastered = false`，回第 1 级，`due = 作答日 + 1`，`wrongCount + 1`。
   - 已掌握、对或部分对：不变。

家长改判任何一次作答后，从起点重新推出，写回派生字段。

## 判对

| 作答形式 | 规则 |
|---|---|
| 选择 | 选中的字母等于 `answer` 为对，否则为错；`judgedBy = "auto"` |
| 短答 | 回答与 `accepted` 中任一项规范化后相等为对，否则为错；`judgedBy = "auto"` |
| 主观 | 提交后显示 `solution`，关键词高亮；她选对、部分对或错；`judgedBy = "self"` |

规范化：转小写；去掉首尾空格，连续空格并成一个；去掉句末的 `.`；两边都是数字时（允许数位间的逗号，例如 `1,000`），按数值比较，`0.50` 与 `0.5` 相等。

家长在家长侧可以把任何一次作答改为对、部分对或错，`judgedBy` 改为 `"parent"`。

## 每日重做

进入时算一次清单，本次进入期间不变：未掌握且 `due` 不晚于今天的错题，按 `due` 从早到晚排，同一天的按 `createdAt` 从早到晚排，取前 `dailyLimit` 题。逐题作答，每题判完立即写回该错题。

## 检验卷

1. 家长选科目、专题（可多选，不选即全部）和题数。
2. 候选：该科目、所选专题内的全部错题，已掌握的也算。
3. 排序：`wrongCount` 从多到少；相同时已掌握的在前；再按 `lastAttemptAt` 从早到晚，从未作答的最先。取前 `count` 题，写成 `papers` 文档，`status = "open"`。
4. 屏幕作答：Sophia 在练习侧打开未做的检验卷，逐题作答，中途不显示对错与答案。交卷后，选择题和短答题自动判；主观题显示讲解，由她自评。全部判完后，每题追加一次 `mode = "paper"` 的作答，检验卷写入 `score`、`status = "done"`。
5. 打印：页面用 `downloads` 保存一份 HTML 文件，家长在浏览器里打开再打印。卷面只有题号、题目、照片、选项与作答空白，答案与讲解另起一页；照片读成内嵌数据，读不到时卷面写明「照片见页面」。纸上做完，家长在家长侧逐题勾选对、部分对或错，`judgedBy = "parent"`，其余同第 4 步。

页面顶部有「Sophia / 家长」切换，不设锁，打开时在练习侧。

| 侧 | 视图 | 内容 |
|---|---|---|

## 照片与文字录入

1. 家长选科目（可选），然后拍照、选照片，或贴一段文字。
2. 有照片时，逐张上传到 `assets`，记下 id。
3. 调 `sample.json`：输入写明任务，附该科目的专题、概念、题型 id 与名称，以及要回的 JSON 形状（一组草稿，每份草稿含 `exercises` 文档除 `images`、`attempts` 与派生字段外的字段）；照片作为 `images` 一起发出。
4. 把回来的每份草稿放进一张可编辑的表单，挂上全部照片。家长逐份核对，可删照片、删草稿、加空白草稿。
5. 保存：每份草稿校验科目与专题必填，写成一份 `exercises` 文档，`attempts` 为空，派生字段按起点写入。

错误分支：

| 情况 | 处理 |
|---|---|
| `sample` 为 `null`，或调用被拒（`not_granted`、`images_unavailable`、`sampling_disabled` 等） | 给一份空白草稿，挂上照片，家长手填；提示识别不可用 |
| `invalid_json`，或回来的不是草稿数组 | 同上，提示识别没有成功 |
| `rate_limited` | 提示稍后再试，不自动重试 |
| 草稿的专题 id 不在体系里 | 专题留空，保存前必须选 |
| 上传照片失败 | 提示失败的照片，其余照常 |

在 Claude Code 对话里录入：agent 先在对话里列出草稿，家长确认后，用 `ArtifactData` 写 `exercises` 文档，字段与派生字段同上；有照片时，先把照片上传到页面的 `assets`，再把 id 写进 `images`。agent 只写 `exercises` 与 `assets`。

## 留白
