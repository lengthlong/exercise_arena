# 0003 题组单独存材料，组里每道错题各算各的阶梯

## 背景

PSLE 里很多题共用一份材料：英文的图文理解、完形与阅读理解是一篇文章或一张传单带几道题，科学是一个实验装置带 (a)(b)(c) 几问。Sophia 往往只错其中几道。原先每道错题自带题目文字与照片，同一份材料只能重复存进每道错题，显示时也重复出现。

## 决定

- 材料单独存成一个题组；错题多一个可选的指向，没有指向的错题照旧是独立的题。
- 复习阶梯仍然逐题计算，题组不另有阶梯。

## 理由

- 材料只存一次、只显示一次，改一处就改全组。
- 指向可选，已经录入的独立错题不用迁移。
- 逐题的阶梯保留了「只重做做错的题」：同组里她做对的题照常升级，不被做错的题拖回去；阶梯、改判与掌握的规则都不用改。

## 代价与被否的方案

- 多一个集合和一个概念；录入、每日重做、检验卷与打印都要按组处理。
- 同组的题会在不同日子到期，偶尔只为一道题重读材料。
- 只给错题加「同组」标签：改动最少，但材料继续重复存放、重复显示。
- 把整份材料连同小题当成一道错题、共用一条阶梯：录入最简单，但做对的小题会被反复重做，「掌握」也要改成整组的状态。
