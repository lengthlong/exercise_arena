# 0002 每位用户用自己的 Claude 账号打开练习场

## 背景

练习场是 claude.ai 上的页面（见 [ADR 0001](./0001-arena-runs-as-claude-artifact-with-db.md)），打开它要登录 claude.ai。现在有三个账号要用它，每人要有自己的设置、作答与复习阶梯。

平台的 `user` 能力给每位看页面的人一个稳定的不透明 id，在拥有本 Artifact 的组织范围内不变。从组织外受邀的 Editor 也拿得到 id 与名字（实测），但拿不到邮箱。`db` 只能按路径与分享级别限制读写，不能按文档里的字段区分。

## 决定

- 每位用户用自己的 Claude 账号打开练习场；谁能打开，由 Artifact 的分享菜单决定。
- 页面按平台 id 认人，数据里只存 id，名字显示时向平台现取。
- 不分学生与家长：全部功能谁都可以用，包括调用 Claude 的照片识别，以及改、删错题与检验卷。
- 错题的归属人决定页面显示、每日重做与组卷用谁的错题；谁都可以在设置里把默认归属人换成另一位，不限制谁能看、能做、能改。

## 理由

- 平台现成的身份免去自建登录；这是用户的选择。
- `db` 不能按字段限权，页面上的限制挡不住受邀者直接改数据。只在页面上做的权限是假的，不如明说谁都能看能改（agent 的论证）。

## 代价

- 受邀者都能读改全部数据；删一道错题会连别人在这道题上的作答一起删掉。
- id 不能跨组织带走：导出的数据里是 id，换到别的组织的副本里对不上人。
- `sophia.zm.shi@gmail.com` 由家长持有使用，在练习场里代表 Sophia 的错题与进度。Anthropic 消费者条款要求用户至少 18 岁，或者达到当地法定同意年龄，取较高者；是否符合条款，由账号持有人按条款原文判断，本 ADR 不下结论。
