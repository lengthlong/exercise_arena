# 0002 Sophia 在家长陪同下用家长账号，调用 Claude 的功能只在家长侧

## 背景

练习场是 claude.ai 上的页面（见 [ADR 0001](./0001-arena-runs-as-claude-artifact-with-db.md)），打开它要登录 claude.ai。Anthropic 消费者条款要求用户至少 18 岁，或者达到当地法定同意年龄，取较高者。Sophia 是小学五年级学生，不能有自己的账号。

## 决定

- 页面只经家长账号打开，Sophia 在家长在场时使用。
- 页面分家长侧和练习侧。录入、改判、组检验卷，以及一切调用 Claude 的功能（照片识别）只在家长侧。练习侧只做看题、作答、看讲解。
- 两侧之间只是页面顶部的切换，不设锁，默认打开练习侧。

## 理由

- 账号的使用者始终是家长；Sophia 在练习侧不和 Claude 对话。
- 家长在场，切换不设锁就够用。口令只能存在页面数据里，起不了真正的保护作用，反而多一个要记的东西。
- 只在纸上做（打印、家长回填结果）能让 Sophia 完全不碰页面，但每次重做都要家长录结果，工作量最大；打印只保留给检验卷。

## 代价

- Sophia 不能独立、随时练习，每次都要家长登录、陪同。
- 本 ADR 不判断这种用法是否符合条款；由家长按条款原文自行判断。

## 未决

- 条款或家庭安排变化时（例如 Sophia 年满可用年龄），是否让练习侧脱离家长账号。
