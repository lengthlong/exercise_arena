## Release notes

- Changing your Default owner no longer makes your weekly balance negative. Coins and balance now count only the library you have selected: coins earned in another library are not mixed in, and stakes of games played in another library are not deducted. Switching back shows the earlier library's figures again.
- A new match remembers which library it was played in (the opener's Default owner when it started). Matches played before this version are attributed by their players' current Default owners.
