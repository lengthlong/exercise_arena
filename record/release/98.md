## Release notes

- **Papers → PSLE is now one shared plan.** Everyone who opens the arena sees the same PSLE 2027 papers in the same weeks. Each person's done dates and scores are their own.
  - If your Default owner is someone else, a "Mine · <name>" switch shows that person's marks, read-only.
  - Changing the plan later never moves papers in weeks that have already passed.
- **Settings → New per week.** A second − / + setting under Questions per day for how many new questions you expect to record each week. Until you set it, your recent recording rate is used.
- **Faster forecast.** Tapping − / + now updates the number and the weekly bars at once. The setting is saved shortly after your last tap, and leaving Settings saves it straight away.
