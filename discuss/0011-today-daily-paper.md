## 二、提议与裁决

### D1 默认归属人默认是自己：是初始值还是固定

证据：E1；0010 里用户原话「The default owner of current user can be changed in 'settings'」。

- A（推荐）**初始值是自己，设置里仍可改成公开或别人。** 没有设置文档或设置里没有这一项时读成自己；用户在设置里明确选「公开」才是公开（存 `null`）。代价：`readSettings` 要知道当前用户是谁，「缺这一项」与「选了公开」要分开存。
- B **固定是自己，设置里去掉这一项。** 每日重做与组卷只取自己的错题，录入默认归自己（录入时仍可改）。代价：推翻 0010 的「设置里可改」，公开错题没人会在每日重做里做到。

**裁决（2026-10-15）：A。** 用户原话：「A. And, delete 'empty' as 'public'.」后半句另立 D1a。

### D1a 「去掉空即公开」指什么

证据：0010 定下归属人为空即公开错题（D3、D3a、D9 的 Owner 词条），默认归属人可选「公开」（D6），检验卷的归属人也可为空（D7a）。用户在 D1 的答复里加了「delete 'empty' as 'public'」。

- A（推荐）**整个去掉「公开」：每道错题都必须有归属人。** 录入时归属人必填（默认自己），设置与录入的下拉框里不再有「公开」，检验卷的归属人也总是一位用户。概念少一个；代价：要改 0010 已落盘的术语、数据契约与断言；以后真有「大家都能做」的题，只能挂在某个人名下，别人把默认归属人换成那个人才在每日重做里做到。
- B **只从默认归属人里去掉「公开」：** 默认归属人只能选一位用户，但错题仍可以没有归属人（录入时可选「公开」）。代价：公开错题仍存在，但每日重做与组卷都按默认归属人取题，没有人会取到它们，实际上没处可做。

**裁决（2026-10-15）：A，整个去掉「公开」。**

### D2 Today 顶部怎样收紧

证据：E2。

- A（推荐）**三行：** 第一行左边「Hi Sophia Shi」、右边小字日期「Thu 15 Oct」；第二行鼓励语，字号缩小、一行写完；第三行一行小字「🔥 1 day in a row · Next badge in 10」（连续天数与下一个徽章并成一行，已得的徽章作小星号跟在后面），去掉两个胶囊框。
- B **两行：** 第一行「Hi Sophia Shi · Thu 15 Oct」，第二行「🔥 1-day streak · next badge in 10」；鼓励语去掉。代价：鼓励语（0006 定下的规则）不再显示。
- C **并进今天的卡片：** 问候与日期作卡片的标题行，连续天数放卡片角上，鼓励语作卡片里的小字。代价：今天的卡片更挤，问候与「要做几题」混在一起。

**裁决（2026-10-15）：A，三行。**

### D3 每日重做怎样作答

证据：E3。用户原话要「re-use the 'exam paper' function … automatically generate a paper for 'x questions to redo today', and the user can do this paper」。

例子：Sophia 今天要重做 23 题。

- A（推荐）**完全按检验卷做：** 点「Start today's redo」，把今天的 23 题排成一张卷（同组的题排在一起），一页列出；全部答完交卷，自动判对；再看答案与讲解、主观题自评；最后「Finish and save」一次写入 23 条作答。代价：中途离开，答过的都不保存；不再每题即时看到对错。
- B **同 A，另把还没交的答案存在这台设备的浏览器里**，回来时接着做。代价：多一份只在本机的草稿，换设备看不到；草稿过期（到第二天、题目变了）要清掉。

**裁决（2026-10-15）：A。** 用户原话：「A. And, save the paper automatically when hand-in. (remove the save button)」后半句另立 D3a。

### D3a 交卷即保存：主观题与检验卷怎么办

证据：E3。现在交卷后只自动判客观题；主观题（`open`）要先看标准答法再自评，「Finish and save」要等每题都有结果才可按。交卷时主观题还没有结果。

- A（推荐）**交卷时客观题立即保存；主观题在自评那一下保存。** 去掉「Finish and save」；交卷后页面停在对答案，主观题每点一次自评就存一条。检验卷与每日卷用同一套流程。代价：主观题没自评就离开，这几题不留作答，下次照常到期。
- B **交卷时全部保存，主观题先记为「自评待定」，之后补评。** 代价：作答多一种未定的结果，阶梯、得分与回顾都要处理它。

**裁决（2026-10-15）：A。**

### D4 每日重做的卷子存不存

证据：E3。卷子存在 `papers` 里时，按 0010 的规则人人可见，会进默认归属人相同的人的 Today，交卷后算进每周目标「Check papers」。

- A（推荐）**不存：** 卷面在点开始时按今天的清单现排，只在页面里；作答照旧写 `mode: "daily"`、`paperId: null`。「检验卷」列表与每周检验卷目标都不变。不加数据与概念。
- B **存成卷子：** `papers` 多一种「每日卷」，记下给谁做；在检验卷列表里留下每天的记录。代价：要从别人的 Today、「Check papers」目标与检验卷列表里把它排除；没做完的旧卷要处理（过期删除或留着）。

**裁决（2026-10-15）：B，存成「每日卷」。** 由此要定的点另立 D4a、D4b。

### D4a 每日卷给谁看、算不算检验卷

例子：Sophia 今天生成了一张 23 题的每日卷。

- A（推荐）**每日卷只属于生成它的人：** 只出现在 Sophia 的 Today 与她的检验卷列表里（标「每日」）；别人看不到、不能做；不算进每周目标「Check papers」。作答记 `mode: "daily"`，带这张卷的 `paperId`。
- B **每日卷像检验卷一样人人可见、可做**，只是不进每周目标。代价：别人的列表里每天多出几张别人的每日卷。

**裁决（2026-10-15）：A。**

### D4b 每日卷何时生成、一天几张、没做完怎么办

证据：现在每日清单按上限截断；做完一轮后，如果还有到期题，Today 会再列出下一批（E2 里 65 道到期、上限 23）。

- A（推荐）**点「Start today's redo」时生成；当天已有没交的每日卷就接着用它。** 交卷后如果还有到期题，Today 照旧显示下一批，可以再生成一张。没交的每日卷到第二天作废：页面不再列出，下次点开始生成新的；旧卷文档留在库里不删（没有作答，不影响阶梯）。
- B **每天第一次打开 Today 时自动生成一张，一天只一张。** 做完就是做完，当天不再出下一批。代价：打开页面就写数据；积压多时一天只能做一个上限。

**裁决（2026-10-15）：A。**

### D6 鼓励语放不进一行怎么办

证据：复审 F1。D2 定的是鼓励语「字号缩小、一行写完」。最长的一句约 50 个字符（如「You mastered 3 today! 12-day streak, keep it going!」），375 宽下缩小字号也可能放不下。

- A（推荐）**放不下时折成两行。** 平常一行，长句偶尔两行。
- B **截短到一行，** 末尾用省略号。代价：长句看不全。

**裁决（2026-10-15）：A。**

### D7 主观题自评存入后还能不能改

证据：复审 F2。D3a 定下主观题「点自评即写一条」。现在对答案页的自评按钮可以反复点、改选；每人每卷每题只该有一条作答。卷面详情页（检验卷列表 →「查看详情」）可以改判自己的作答。

- A（推荐）**存入后锁定，** 自评按钮变成只读的结果；要改去卷面详情改判。
- B **可以改，** 再点一次就改写同一条作答（改判）。代价：对答案页多一条改写路径。

**裁决（2026-10-15）：A。**

### D8 怎样算「交过」一张卷

证据：复审 F3。现在按「我在这张卷上有作答」算交过。一张卷全是主观题时，交卷后不自评就离开，就一条作答都没有：每日卷下次点「Continue」会打开同一张空白卷，检验卷会再显示「开始」。真实数据里 86 道题只有 7 道主观题，全是主观题的卷子很少见。另一点：当天改了默认归属人或每日上限后，早上那张没交的每日卷是否照用。

- A（推荐）**照现在的算法，不另记；当天没交的每日卷改了设置也照用。** 全是主观题又没自评的卷子当作没交过，可以重做。不加数据。
- B **交卷时在卷子上记下「谁交过、何时交」，** 以它为准。代价：卷子多一个按人记录的字段，几个人交同一张检验卷时要同时写这份文档。

**裁决（2026-10-15）：B。** 落实：卷子加 `handedIn`（用户 id → 交卷时刻）；交卷时读出原值、加上我的一项再写回，两人同时交同一张检验卷时后写的可能覆盖先写的（与作答的并发代价同类）。旧卷没有 `handedIn` 时按「我有作答」算，完成时刻取最晚的作答。当天改了设置后，没交的每日卷照用（两个选项都未改变这一点，确认核销表时一并请用户看）。

### D5 术语表要不要加「每日卷」

证据：现在「Check paper（检验卷）」定义为「选定科目、专题和题数后…抽出的一次性小测，用来确认掌握」；每日卷是每日重做按清单生成的卷子，不是检验卷（D4a）。「Daily redo（每日重做）」的定义只说列出哪些题。

- A（推荐）**加一条「Daily paper（每日卷）」：** 为一位用户的每日重做按当天清单生成的卷子，只给这位用户做，不算检验卷。`_Avoid_`：每日试卷、今日卷。Daily redo 的定义补「以每日卷作答」。
- B **不加词条，** 只在 Daily redo 的定义里写「以卷子的形式作答」。代价：界面与数据里有「每日」这一种卷子，术语表里却没有它的名字。

**裁决（2026-10-15）：A。** 定稿词条：

```markdown
### Daily paper（每日卷）

为一位用户的每日重做、按当天清单生成的卷子。只给这位用户做，不算检验卷。

_Avoid_: 每日试卷、今日卷
```
