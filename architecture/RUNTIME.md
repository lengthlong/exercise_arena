# 运行时场景

## 照片录入

在录入页拍下一页卷子，页面把照片存进 `assets`，请 Claude 拆成草稿，逐条确认后保存。几道题共用一份材料时，Claude 另拆出一份题组草稿，这批照片挂在题组上；没有题组时，照片挂在每份错题草稿上。识别不可用或拆得不准时，在同一张表单里手填，原照片照样挂在草稿上。

```plantuml
@startuml
actor 用户
participant "练习场页面" as Page
participant assets
participant "sample" as Sample
database db

用户 -> Page : 选科目，拍照或选照片
Page -> assets : upload(照片)
assets --> Page : 照片 id
Page -> Sample : 照片 + 专题、题型清单 + 输出格式
alt 识别成功
  Sample --> Page : 题组草稿（可无）与错题草稿
else 未授权、失败或格式不对
  Page -> Page : 给出一张空白草稿，挂上照片
end
用户 -> Page : 逐条核对、修改草稿
用户 -> Page : 保存
Page -> db : 写 sets（组内第一道保存时）
Page -> db : 写 exercises（第 1 级，次日到期）
@enduml
```

## 对话录入

在 Claude Code 对话里发文字或照片。agent 先把题组与错题草稿列在对话里，确认后，agent 用 `ArtifactData` 写进 `sets` 与 `exercises`；有照片时，先把照片传进 `assets`，再把 id 写在题组或错题上。

## 每日重做

Sophia 在 Today 打开每日重做，逐题作答。选择、选词与短答题提交后立即判对；主观题提交后显示讲解与得分关键词，由她自评。有必须用的词的主观题，提交前先检查，没用到或写成多句时提醒，她可以改，也可以照交。每次作答写进该错题的作答记录，并按复习阶梯更新它的级与到期日。同一题组当天到期的题连在一起，材料在第一题完整显示，之后默认收起；题目与材料的照片另行默认收起，点开才显示。

## 检验卷

选科目、专题和题数，页面抽题生成检验卷。抽中的同组错题在卷面上排在一起，材料只出现一次。Sophia 在 Today 打开检验卷，一次做完、交卷，交卷前对各题统一提醒必须用的词，交卷后才看到答案，主观题自评。每道题的结果都写成一次作答，并更新阶梯；检验卷记下完成时刻。得分由这些作答算出；可以在检验卷详情里逐题改判，得分随之变化。
